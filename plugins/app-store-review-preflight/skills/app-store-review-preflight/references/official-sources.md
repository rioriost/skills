## Refresh rules

1. Read the current App Review Guidelines introduction, `Before You Submit`, and all five top-level sections.
2. Follow Apple links for every feature present in the app; do not use search-result snippets as normative text.
3. Prefer the platform-specific Apple documentation matching the selected build.
4. Record the guideline page's displayed `Last Updated` date when available.
5. If a bundled matrix number or wording differs from Apple, Apple wins. Report the updated number and wording.
6. Cite direct Apple pages, not search results, secondary articles, or remembered review messages.
